# 📚 SIM-BK (Sistem Informasi Bimbingan Konseling)

Aplikasi berbasis web untuk mengelola data bimbingan konseling siswa secara digital dan terstruktur. Dibangun menggunakan **PHP Native** dan **MySQL**.

---

## 🚀 Fitur Utama
- **Manajemen Data Siswa:** Pencatatan dan pengelolaan profil siswa yang bermasalah atau membutuhkan bimbingan.
- **Pencatatan Konseling:** Input sesi bimbingan, catatan kasus, dan penanganan secara rahasia dan aman.
- **Laporan Bimbingan:** Rekapitulasi laporan berkala untuk pihak sekolah.
- **Autentikasi Login:** Sistem hak akses aman untuk admin/guru BK.

---

## 🔑 Akun Demo (Login)
Bagi yang ingin mencoba menjalankan dan masuk ke dalam aplikasi secara lokal, gunakan kredensial berikut:
- **Username:** `admin`
- **Password:** `1234`

---

## 🛠️ Teknologi yang Digunakan
- **Bahasa Pemrograman:** PHP Native, JavaScript
- **Database:** MySQL (phpMyAdmin)
- **Server Lokal:** XAMPP

---

## ⚙️ Cara Menjalankan Aplikasi Secara Lokal
1. Pastikan **XAMPP** sudah terinstal di komputermu.
2. Clone repository ini atau download sebagai ZIP ke dalam folder `htdocs` XAMPP (`C:\xampp\htdocs\Sim-bk`).
3. Nyalakan modul **Apache** dan **MySQL** melalui XAMPP Control Panel.
4. Buat database baru di phpMyAdmin, lalu import file database proyek ini.
5. Buka browser dan ketik alamat:
   ```text
   http://localhost/Sim-bk/
